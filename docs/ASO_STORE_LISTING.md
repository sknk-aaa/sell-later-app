# App Store 掲載文（ASO）

ASCにコピペする掲載テキスト。英語(主)・日本語(副)。文字数はASC制限に準拠（App名30 / サブタイトル30 / キーワード100 / 説明は長文可）。

> **ASO方針**: 競合（英米）はほぼ全員が「reseller/flipper＝せどり業者向け」のプロツール。日本もフリマ本体・買取・再出品メモに分散。**両市場とも「一般人が"家にある不用品の資産価値"を見える化する」ポジションが空白**。ここを主軸に、せどり業者向けの語彙（cross-listing/bulk/sourcing）はあえて避け、declutter/secondhand/"what's it worth"層を取りに行く。

## 説明文
```
家に眠っている「いつか売る物」、全部でいくらになるか知っていますか？

うるカタは、売ろうと思って放置している物を「資産」として見える化するアプリです。写真を撮って値段を入れるだけ。全部売ったらいくらになるかが、ホームでひと目でわかります。

業者向けの難しい在庫管理ツールではありません。クローゼットや押し入れ、引き出しに眠っている物の「隠れた価値」を、シンプルに美しく確認できます。

◆ 主な特徴
・全部売ったらいくら？ … 合計額がホームでひと目でわかる
・登録は数秒 … 写真→値段でかんたん登録
・売却まで記録 … 「売る予定」から「売却済み」まで、実際の利益も記録
・手数料も自動計算 … メルカリ・eBay・Poshmark等の手数料プリセットで正確な利益を表示

・断捨離して、不用品をお金に変えたい
・たまにフリマで物を売る（業者ではない）
・クローゼットの整理が本当に得になるか知りたい

「全部売ったらいくら」を見える化して、売るたびに増える合計額を楽しもう。

Proにアップグレードすると、商品数無制限・写真複数枚・全分析機能の解放・広告非表示になります。
```

## 登録時の注意
- **キーワード欄**: App名・サブタイトルに入れた語は繰り返さない（重複は無駄）。Appleは自動でApp名/サブタイトルの語もインデックスする。
- **メルカリ等の商標**: 説明文での「対応プラットフォーム」言及はOK。App名に他社商標を入れるのは審査リスクがあるため避けた（"フリマ出品管理"に留めた）。
- **文字数**: ASCで実際に貼って超過したら、キーワードは優先度の低い末尾語から削る。
