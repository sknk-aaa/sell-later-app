# Marketing

Worthnest / うるカタのストア訴求、ASO仮説、スクリーンショット、SNS/動画台本、価格/広告/Pro導線AB案を蓄積する場所。確定済みのApp Store掲載文は `docs/ASO_STORE_LISTING.md`、現在の作業状態は `docs/HANDOFF.md` に置く。

## 目的

- 一般ユーザーに「家に眠っている物の価値が見える」体験を伝え、登録、継続、Pro購入、広告収益につなげる。
- 実装相談でも、初見の伝わり方、ストアCV、レビュー、広告/Pro導線、継続利用への影響を同時に見る。

## 基本方針

- 海外向けは Worthnest を主役にする。日本向けは「うるカタ」/「売り物カタログ」を使う。
- コア訴求は「全部売ったらいくら？」「クローゼットの隠れた価値」「断捨離をお金に変える」。
- 業者向けの在庫管理・せどりツールに見せすぎない。一般ユーザーが家にある物を写真と値段で見える化するアプリとして伝える。
- Pro訴求は、商品数無制限、写真複数枚、分析、広告非表示を「本気で片付けて売る人向け」に整理する。

## 避けること

- cross-listing / sourcing / bulk listing など、業者向けツールに寄りすぎる語彙。
- メルカリ等の他社商標をApp名・見出しで過度に使うこと。説明文での対応先言及に留める。
- 為替換算や販売価格の保証があるように見える表現。
