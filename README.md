# sell-later-app

「いつかメルカリで売る物」を管理するiOSアプリ（React Native + Expo SDK54）。

開発の引き継ぎ・現状・注意点は **[docs/HANDOFF.md](docs/HANDOFF.md)** を参照。
設計書は [docs/sellitlater_design_v1.md](docs/sellitlater_design_v1.md)。

## 開発
```
npx expo start -c --tunnel   # Expo Go(SDK54)で確認
npx tsc --noEmit             # 型チェック
```
